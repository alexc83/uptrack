# Attach a Certificate to a CE Record

UpTrack allows you to attach a certificate to a continuing education (CE) record so you can keep supporting documentation alongside your completed activities.

Each CE record can have one attached certificate.

## Before you begin

You must have at least one credential in UpTrack before creating a CE record.

You can attach a certificate when creating a new CE record or editing an existing one.

## Attach a certificate to a new CE record

1. Log in to UpTrack.
2. Select **CE Records** from the navigation menu.
3. Select **Add CE Record**.
4. Complete the required CE activity information.
5. Locate the **Certificate** field.
6. Select a certificate file from your device.
7. Wait for the message **Certificate uploaded successfully.**
8. Select **Save CE Record** to save the activity with its certificate.

Your certificate will be associated with the CE record once the record is saved successfully.

## Attach a certificate to an existing CE record

1. Open the **CE Records** page.
2. Find and select the record you want to update.
3. Select **Edit CE Record**.
4. Locate the **Certificate** field and choose your file.
5. Wait for the upload to finish.
6. Select **Save Changes**.

You can open the CE record afterward to view its attached certificate.

## Supported file formats

UpTrack accepts the following certificate formats:

- PDF (.pdf)
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WEBP (.webp)
- GIF (.gif)

Files must be **5 MiB or smaller**.

For security, UpTrack may reject PDF files containing interactive forms, encryption, embedded files, or other unsupported content.

If your PDF is rejected, try exporting or printing it as a standard, non-interactive PDF before uploading it again.

## Important to know

**Uploading and saving are separate steps.** UpTrack uploads your selected file immediately, but you must still save the CE record to attach the certificate to that activity.

If you cancel without saving, the uploaded file will not be attached to the CE record. UpTrack's cleanup process handles abandoned uploads.

Each CE record supports one certificate. If you need to update an existing attachment, you can replace it with a new file.
