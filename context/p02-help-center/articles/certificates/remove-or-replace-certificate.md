# Remove or Replace a Certificate

You can remove or replace a certificate attached to a continuing education (CE) record in UpTrack.

This is useful if you've uploaded the wrong file, received an updated certificate, or no longer need an attachment.

Each CE record can have one attached certificate.

## Remove a certificate

To remove a certificate without deleting its CE record:

1. Log in to UpTrack.
2. Select **CE Records** from the navigation menu.
3. Find and select the CE record containing the certificate.
4. In the record details panel, locate the **Certificate** section.
5. Select **Remove Certificate**.

UpTrack removes the certificate attachment from the CE record. The CE activity and its recorded hours remain unchanged.

**Important:** Removing a certificate from the record details panel takes effect immediately. There is no additional confirmation step.

## Replace a certificate

To replace an existing certificate with a different file:

1. Open **CE Records**.
2. Find and select the CE record you want to update.
3. Select **Edit CE Record**.
4. In the **Certificate** field, choose your replacement file.
5. Wait for the message **Certificate uploaded successfully.**
6. Select **Save Changes**.

The new certificate will be attached to the CE record, replacing the previous file.

You can return to the record details and select **View certificate** to open the replacement.

## Remove a certificate while editing

You can also remove a certificate from the CE record editing form.

1. Open the CE record and select **Edit CE Record**.
2. Locate the attached certificate.
3. Select **Remove certificate**.
4. Select **Save Changes** to complete the change.

Unlike removing a certificate directly from the record details panel, changes made in the editing form must be saved.

## What happens to removed files?

When you remove or replace an UpTrack-managed certificate, UpTrack schedules the previous file for deletion from its storage service.

File cleanup may take additional time if the storage service is temporarily unavailable. UpTrack automatically retries eligible cleanup operations.

Removing or replacing a certificate does not delete the CE activity or change its recorded CE hours.

## Important to know

- Each CE record supports one certificate at a time.
- Removing a certificate does not delete the CE record.
- Replacing a certificate requires uploading the new file and saving your changes.
- Removed attachments cannot be restored through the UpTrack interface. Keep a separate copy of any certificate you may need later.
