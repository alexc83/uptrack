# My Certificate Won't Upload

If you're having trouble uploading a certificate to UpTrack, the issue may be related to the file format, file size, or the contents of the document.

Use the troubleshooting steps below to identify the problem.

## Check your file format

UpTrack accepts the following certificate file types:

- PDF (.pdf)
- JPEG (.jpg, .jpeg)
- PNG (.png)
- WEBP (.webp)
- GIF (.gif)

Other file formats are not supported.

If you see **"Unsupported certificate file type"**, check that your file is saved in one of the supported formats.

Changing a file's extension does not convert it to a different format. If necessary, open the document in a compatible application and export it as a supported file type.

## Check your file size

Certificate files must be **5 MiB or smaller**.

If your file exceeds this limit, UpTrack will display:

**"Certificate files must be 5 MiB or smaller."**

Try reducing the file size by compressing the PDF or saving the image at a lower resolution.

Make sure the document remains readable before uploading it again.

## Your PDF was rejected

For security reasons, UpTrack checks uploaded PDF files for unsupported content.

Some PDFs may be rejected even if they open normally on your device.

This can happen when a PDF contains:

- Interactive forms or form fields
- Encryption or password protection
- Embedded files
- Scripts or other active content

If you see **"Certificate content is invalid or does not match its file type"**, try the following:

1. Open the original PDF on your device.
2. Use your PDF application's print or export feature to create a new, standard PDF without interactive elements.
3. Save the new file.
4. Return to UpTrack and try uploading it again.

If the problem continues, contact the organization that issued your certificate for a standard PDF copy.

## Your image was rejected

UpTrack also checks uploaded images to make sure they're valid and within supported limits.

Images with extremely large dimensions or more than 100 frames may be rejected.

Try resizing the image or saving it as a standard JPEG or PNG file, then upload it again.

## The upload service is busy

If you see **"The upload service is busy. Please try again shortly."**, UpTrack is temporarily unable to process your file.

Wait briefly and try uploading again.

If you see **"Too many requests. Please try again later."**, wait before attempting another upload.

## The upload failed unexpectedly

If you see **"Certificate upload failed"** or a connection error:

1. Check your internet connection.
2. Make sure your UpTrack session is still active.
3. Refresh the page if necessary.
4. Return to the CE record and try uploading the file again.

If the problem continues, try again later.

## Confirm your certificate was attached

After a successful upload, UpTrack displays:

**"Certificate uploaded successfully."**

Remember that uploading and saving are separate steps.

Select **Save CE Record** or **Save Changes** to attach the uploaded certificate to your CE activity.

You can then open the CE record and look for **View certificate** to confirm the attachment is available.
