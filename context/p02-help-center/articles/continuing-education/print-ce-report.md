# Print a CE Report

UpTrack provides a printable report of the continuing education activities associated with an individual credential.

## Open the CE report

1. Open **Credentials**.
2. Select the credential you want to review.
3. Select **Open CE Report**.
4. Review the credential information and associated CE entries.

## Print the report

1. On the CE report page, select **Print**.
2. Use your browser's print dialog to choose a printer or, where supported, save the page as a PDF.
3. Check the print preview and complete the action.

UpTrack uses the browser's print function; it does not currently provide a separate CSV or PDF export feature.

## Review the information

The report reflects the CE records attached to that credential. UpTrack does not automatically verify whether each activity falls in the required renewal period. Check dates and requirements before submitting a report to an issuing organization.
