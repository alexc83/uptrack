# UpTrack Git Hooks

This directory contains version-controlled, opt-in Git hooks designed to enforce UpTrack's Git attribution policy before commits are created.

## Purpose

Per the canonical Git attribution policy in `AGENTS.md`:
1. All owner-authored commits must use the repository owner's configured identity:
   - Name: `alexc83`
   - Email: `alexc83@users.noreply.github.com`
2. AI agents (Claude, Mistral Vibe, OpenAI Codex, Gemini, etc.) must never be used as commit author or committer.
3. Commit messages must never contain AI attribution trailers or statements (`Co-Authored-By`, `Signed-off-by`, `Generated by`, `🤖 Generated with...`, etc.).
4. Legitimate automated Dependabot activity is accommodated and not obstructed.

## Included Hooks

- `pre-commit`: Validates Git author and committer identity before entering commit message authoring.
- `commit-msg`: Validates Git author, committer, and the prepared commit message content, rejecting unauthorized trailers or AI attribution statements before the commit object is created.

Both hooks delegate to the shared validator script:
- `scripts/validate-git-attribution.sh`

## How to Enable Locally (Opt-In)

Run the installation script from the repository root:
```bash
./scripts/install-git-hooks.sh
```

Or configure Git directly:
```bash
git config core.hooksPath .githooks
chmod +x .githooks/* scripts/validate-git-attribution.sh
```

## How to Disable

Run the uninstall script:
```bash
./scripts/uninstall-git-hooks.sh
```

Or configure Git directly:
```bash
git config --unset core.hooksPath
```

## Manual / Standalone Verification

You can validate Git identity and commit messages independently at any time:

```bash
# Check current Git identity resolution:
./scripts/validate-git-attribution.sh --check-ident

# Check a commit message file:
./scripts/validate-git-attribution.sh --check-msg path/to/commit-msg-file

# Run the automated test suite:
./scripts/test-git-attribution-hook.sh
```
